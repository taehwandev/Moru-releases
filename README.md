# Moru

Releases of the Moru desktop app for macOS. Download the latest DMG from [Releases](https://github.com/taehwandev/Moru-releases/releases/latest).

Moru was previously called Tao; copies installed as Tao do not update to Moru by themselves, so install Moru from here. Your Projects and Tasks carry over.

## Open source: Moru Community Edition

The IDE core of an earlier Moru app is open source under Apache-2.0, written in Kotlin Multiplatform and Compose Multiplatform: Projects and Tasks, real terminals (PTY), an agent session list, a Result pane with the changed code, and a Git screen. It is in maintenance mode.

Source: [`kmp` branch](https://github.com/taehwandev/Moru-releases/tree/kmp). It is separate from the Moru app above and keeps its own data folder. Documentation: [English](https://github.com/taehwandev/Moru-releases/blob/kmp/README.md) · [한국어](https://github.com/taehwandev/Moru-releases/blob/kmp/README.ko.md) · [简体中文](https://github.com/taehwandev/Moru-releases/blob/kmp/README.zh-CN.md) · [日本語](https://github.com/taehwandev/Moru-releases/blob/kmp/README.ja.md)
